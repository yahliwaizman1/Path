## ❓ Q&A Preparation

### Expected Questions:

**Q: "How accurate is the AI?"**
> "It's rule-based AI using keyword detection. It's explainable - every decision is justified. We can see exactly why a student was flagged. For production, we'd add machine learning to improve pattern detection."

**Q: "What if teachers don't write comments?"**
> "The system still works with grades and absences alone. But teacher comments add valuable context. Our data shows most teachers naturally document concerns - we just extract insights from their notes."

**Q: "Can parents see this?"**
> "Not in this demo, but a production version would include a parent portal with progress graphs and recommendations."

**Q: "How do you prevent false positives?"**
> "Yellow (early warning) flags students for monitoring, not intervention. We use thresholds: Only 🔴 Red triggers urgent action. Yellow means 'watch closely.'"

**Q: "What about data privacy?"**
> "Student data stays in the school's system. In production, we'd implement role-based access control and comply with educational data privacy laws."
